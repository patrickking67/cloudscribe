Scripts that fail at compile time, not on the server.

CloudScribe is a small typed language for the scripts that check hosts, loop over services and read config. It rejects a typo or a string where a number belongs before anything runs, then compiles to plain JavaScript for Node.js. The compiler below is the real one, running in this page.

How a file compiles

        
Four stages, each in its own file with its own tests. A syntax or type error stops the pipeline before any JavaScript exists. The whole compiler is about 1,600 lines with no build step.

What the compiler rejects

          
Every error stops compilation and points at the line and column, with the offending code underlined.

          
    
            
  • Undeclared, redeclared and unknown names, including unknown type names
    • 
            
  • Type mismatches in assignments, arguments, returns, array elements and comparisons
    • 
            
  • Interpolating a value that is not an int, string or boolean, such as an array or an optional with no fallback
    • 
            
  • Conditions that are not boolean, and for ... in over something that is not an array
    • 
            
  • Calls to things that are not functions, and calls with the wrong number of arguments
    • 
            
  • Assigning to a const, a loop variable or a task
    • 
            
  • break outside a loop and return outside a function or task
    • 
          

        

        
      

    


    

      

        
Built-in functions

        
Enough to read settings, touch files and call other tools. Functions that can come back empty return an optional, so the compiler makes you supply a fallback with ??.

        

          

            
              
SignatureWhat it does

            
            
              
print(value)Writes a line to stdout

              
env(name: string): string?Reads an environment variable

              
readFile(path: string): stringReads a UTF-8 file

              
writeFile(path: string, text: string)Writes a UTF-8 file, replacing it

              
fileExists(path: string): booleanChecks that a path exists

              
toInt(text: string): int?Parses a whole number, or gives nothing

              
shell(command: string): stringRuns a command and returns its output

              
exit(code: int)Stops the program with an exit code

            
          

        

      

    


    

      

        
How it is tested

        
One command, npm run check, runs everything locally and in CI. The numbers below come from that command and a test fails if the test count here goes stale.

        

          

            
285 tests

            
One suite per compiler stage, plus the CLI, built-ins, examples, playground and this site. Node's built-in runner, no test framework.

          

          

            
99.2% line coverage

            
Of src/, measured by Node's native coverage on Node 24. Branch coverage is 95.8%.

          

          

            
Node 20, 22 and 24

            
CI runs the same check on all three for every push and pull request, with read-only permissions.

          

          

            
10 examples executed

            
Every program in examples/ is compiled, run in an empty directory and compared with its expected output.

          

        

        

          Generated code is checked by running it, not only by matching strings. The copy of the compiler in this
          page is compared with src/ on every run, so the playground cannot drift from the CLI.
          See the test suites and the
          CI runs.
        

      

    


    

      

        

          
Install

          
Needs Node.js 20 or later. Clone the repository, then link the CLI so cloudscribe is on your path.

          
Exit code 0 means success, 1 a syntax or type error, 2 a bad argument or unreadable file. With --run you get the program's own exit code.

        

        
git clone https://github.com/patrickking67/cloudscribe.git
cd cloudscribe
npm ci
npm link

cloudscribe examples/config_check.csc --check
cloudscribe examples/config_check.csc --run
cloudscribe examples/config_check.csc --out check.mjs
